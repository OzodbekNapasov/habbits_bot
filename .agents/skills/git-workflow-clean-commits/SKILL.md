# Git Workflow Skill

## Guidelines
1. **Conventional Commits**: Format commit messages as `feat:`, `fix:`, `docs:`, `refactor:`, `test:`.
2. **Small Atomic Commits**: Keep each commit focused on a single logical change.
3. **Branching**: Use feature branches (`feat/name`) and merge into `main`.
4. **Clean .gitignore**: Exclude local build artifacts, environment secrets, and OS junk files.
5. **No Force Push Main**: Protect `main` branch and avoid force pushing shared branches.
