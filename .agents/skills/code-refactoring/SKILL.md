# Code Refactoring Skill

## Guidelines
1. **DRY (Don't Repeat Yourself)**: Extract repeated logic into reusable helper functions.
2. **Single Responsibility**: Ensure each module, class, and function has one clear task.
3. **Small Functions**: Keep functions under 30 lines for maximum readability and testability.
4. **Meaningful Naming**: Use clear, descriptive variable and function names.
5. **Remove Dead Code**: Delete unused imports, functions, and commented-out legacy code.
