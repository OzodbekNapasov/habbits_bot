# Modern Web UI Skill

## Guidelines
1. **Visual Excellence**: Use sleek dark mode, soft glassmorphism, and smooth linear gradients.
2. **Modern Typography**: Use Google Fonts (e.g. Inter, Roboto, Outfit) with clear hierarchy.
3. **Interactive Hover & Focus**: Add smooth CSS transitions (`ease-in-out 0.2s`) for active states.
4. **Responsive Layouts**: Use CSS Grid and Flexbox for seamless adaptation across mobile & desktop.
5. **Semantic Elements**: Use HTML5 `<header>`, `<main>`, `<section>`, `<article>`, `<footer>`.
