# React & Next.js Expert Skill

## Guidelines
1. **Server vs Client**: Use Server Components by default; add `'use client'` only when interactivity is needed.
2. **Data Fetching**: Fetch data in Server Components or use React Query / SWR on client.
3. **Image Optimization**: Use Next.js `<Image />` component for responsive images.
4. **Route Handlers**: Implement clean API routes in `app/api/route.ts`.
5. **Layouts & Suspense**: Use Suspense boundaries for streaming UI and loading states.
