# Unit Testing Skill

## Guidelines
1. **AAA Pattern**: Structure tests using Arrange, Act, Assert.
2. **Mocking External I/O**: Mock database, network requests, and external APIs in unit tests.
3. **Edge Case Coverage**: Test null inputs, boundary values, empty arrays, and error handling paths.
4. **Fast Execution**: Keep unit tests fast so they run seamlessly in development and CI.
5. **Determinism**: Avoid dependency on real timers or live network services; use fake timers.
