# Tailwind CSS Design System Skill

## Guidelines
1. **Curated Color Palette**: Use cohesive Tailwind colors (slate, indigo, emerald) with proper contrast.
2. **Dark Mode Support**: Leverage Tailwind `dark:` variant classes for dark mode.
3. **Reusable Components**: Extract recurring utility patterns into clean UI component functions.
4. **Responsive Classes**: Mobile-first design using `sm:`, `md:`, `lg:`, `xl:` breakpoints.
5. **JIT Compilation**: Maintain clean `tailwind.config.js` and avoid arbitrary values when tokens exist.
