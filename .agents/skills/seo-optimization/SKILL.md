# SEO Optimization Skill

## Guidelines
1. **Meta Descriptions & Titles**: Provide unique, descriptive title tags and meta descriptions per page.
2. **OpenGraph & Social Tags**: Add `og:title`, `og:description`, `og:image`, and `twitter:card` tags.
3. **Single H1 Tag**: Ensure exactly one `<h1>` tag per page with structured heading hierarchy.
4. **Semantic HTML**: Use `<header>`, `<nav>`, `<main>`, `<article>`, `<aside>`, `<footer>` tags.
5. **Fast Load Times**: Optimize images, fonts, and scripts to excel at Core Web Vitals.
