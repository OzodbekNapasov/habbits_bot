# Code Review Checklist Skill

## Guidelines
1. **Correctness**: Does the code fulfill requirements and cover edge cases?
2. **Security**: Are inputs validated? Are secrets protected? Is authorization checked?
3. **Performance**: Are there unindexed queries, blocking loop operations, or memory leaks?
4. **Readability**: Is the code clean, modular, well-named, and properly typed?
5. **Testability**: Are there tests covering key logic paths?
