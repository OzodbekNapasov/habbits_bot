# Mobile Responsive Design Skill

## Guidelines
1. **Mobile-First Layout**: Write CSS mobile styles first, then expand layout via `@media (min-width: ...)`.
2. **Touch Target Size**: Ensure interactive buttons and links have at least 44x44px touch area.
3. **Viewport Meta**: Include `<meta name="viewport" content="width=device-width, initial-scale=1.0">`.
4. **Flexible Images**: Set `max-width: 100%; height: auto;` on images to prevent layout overflow.
5. **Test Screen Sizes**: Verify UI across mobile (375px), tablet (768px), and desktop (1440px) breakpoints.
